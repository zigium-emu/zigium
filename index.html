Get your hands on it

Built from source.
Open to curiosity.

Install Zig, clone the repository, and run the included demos or open the desktop GUI. The Windows GUI requires the Vulkan SDK and its VULKAN_SDK environment variable. Use -Dvulkan=false for the core CLI.

↳Requires Zig 0.17.0
$ git clone https://github.com/zigium-emu/zigium.git
$ cd zigium
$ zig build
$ zig build test
$ zig build demo
$ zig build services-demo

The included hello and SM/APM service NROs are verified on Windows.

$ zig build run
$ zig build run -- --gui app.nro

$ zig build run -- app.nro

No arguments opens the GUI; --gui loads into it. A direct path runs through the CLI. Compatibility remains limited.

Inside the project

A small frontend.
A modular core.

The desktop and command-line frontends load homebrew into the same core. CPU execution, permission-checked guest memory, and Horizon services have their own boundaries.

NRO / NSO→Guest core→Vulkan

Software framebuffers pass through VI/Binder and Tegra layout conversion before Vulkan presentation. Maxwell shader and draw execution remain future work.

CPU
AArch64 interpreter with integer and partial FP/SIMD execution. Unsupported instructions stop with diagnostics; JIT compilation is pending.
Memory
Guest virtual address space, mapped regions, permissions, and checked access.
Kernel
Horizon SVC handling and HLE services. Original SM/APM service homebrew runs successfully.
Loader
NRO/NSO loading and homebrew entry setup. NCA loading and general filesystem access are pending.
GPU / Vulkan
Guest software framebuffer decoding and verified Vulkan upload, presentation, and GPU readback on Windows.
HID / Audio
Keyboard input reaches guest HID shared memory, including both sticks and buttons. Audio is unimplemented.

Where things stand

A real beginning.
A clear next step.

Space Game NX 1.1 reaches gameplay. Starting, movement, stick shots, and sustained mouse aiming/fire are verified with real host input and GPU readback images.

DEVELOPMENT SNAPSHOT

The original hello and SM/APM service NROs execute successfully, including a Vulkan GUI run. A short Space Game NX sample measured 8.6 guest FPS on an RTX 5070 Ti: functional gameplay remains slow. Its old SDL build can require repeated movement taps. General filesystem access, NCA loading, audio, Maxwell shader/draw execution, and JIT compilation remain pending. Broader homebrew compatibility is unverified.
